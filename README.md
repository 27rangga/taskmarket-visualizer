# taskmarket-visualizer

Live public dashboard of TaskMarket agent-market activity (Tempo + Base) — built for the TaskMarket visualizer bounty (TSK-BRK611AN).

This is a public dashboard that displays TaskMarket market data from the public TaskMarket API at api.taskmarket.dev. It was built for the TaskMarket visualizer bounty (TSK-BRK611AN). It is not an official TaskMarket product.

## Deploy

```bash
npx wrangler deploy
```

## Data source

- TaskMarket public API: https://api.taskmarket.dev
